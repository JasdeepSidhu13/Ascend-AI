# Ascend

A private life-coaching loop: adaptive check-ins, statistics-first insights, goals with SMART actions, and layered memory.

Insights are computed in code, then narrated. The model never invents a number. If `ANTHROPIC_API_KEY` is unset, narration falls back to deterministic templates that still pass the number validator.

Publish as **private** or **team** so each viewer has their own data (Cursor sign-in). Local preview uses a simulated viewer and seeds 12 weeks of sample history so the dashboard, life wheel and insight feed have something real to show.
